## Exit criteria

- Pre-merge: lint, typecheck, unit and smoke green on 3 engines; coverage ≥ 90 % (project thresholds); SonarQube gate passed; gitleaks clean; JRN-01…03 pass.
- Release: pre-merge criteria + `/qa full` with no open Must; Lighthouse performance ≥ 90 on desktop; no axe-core serious / critical violation.
